# 👶 Chá do Dominic — Convite Interativo & Confirmação de Presença

![Status](https://img.shields.io/badge/Status-Concluído-brightgreen)
![Projeto](https://img.shields.io/badge/Projeto-Pessoal-blue)

> Um site simples, moderno e afetuoso criado para centralizar as informações do Chá de Bebê do Dominic, facilitar a confirmação de presença dos convidados e apresentar a lista de mimos.

---

## 💡 Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de oferecer uma experiência digital prática e intuitiva para familiares e amigos. Em vez de convites tradicionais em papel ou mensagens dispersas, o site unifica tudo o que o convidado precisa em um só lugar.

### ✨ Funcionalidades
* 📍 **Informações do Evento:** Data, horário e localização do evento.
* 📩 **Confirmação de Presença (RSVP):** Formulário direto para os convidados confirmarem presença.
* 🎁 **Lista de Mimos / Sugestões:** Organização das sugestões de presentes para os convidados.
* 📱 **Layout Responsivo:** Acessível e adaptado para telas de smartphones e computadores.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5** — Estruturação semântica da página.
* **CSS3** — Estilização personalizada, layout responsivo e transições.
* **JavaScript** — Interatividade e manipulação de formulários/eventos.
